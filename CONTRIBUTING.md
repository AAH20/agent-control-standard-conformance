# Contributing

Open an issue before adding a named vendor comparison or materially interpreting a normative requirement. Each vector needs a threat, precondition, observable side effect, expected verdict, evidence contract, negative control and test. Each adapter must identify which boundaries are real, simulated or untested.

Do not use “certified,” OWASP branding or claims of endorsement. Pin external specification revisions. Run `python -m unittest discover -s tests -v` before submitting.
